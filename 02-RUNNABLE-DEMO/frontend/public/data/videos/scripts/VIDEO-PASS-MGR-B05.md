Scenario: You have many accounts and struggle to remember a different strong password for each one. Safest response: Option D: Use an organization-approved password manager with a strong protected vault and unique generated passwords. An approved manager helps maintain distinct credentials without requiring people to memorize them all. Option A is unsafe because Reuse creates cross-account risk when any one service is breached. Option B is unsafe because A shared, unprotected note exposes multiple accounts to anyone with access to the device. Option C is unsafe because Email may be accessible to mailbox attackers and is not an appropriate password vault. In practice: Use an organization-approved password manager, secure its master authentication, and never store real passwords in the learning simulation. Key takeaway: A trusted password manager supports unique credentials; protect the vault itself carefully.
