## Learning objective
Avoid enabling active content in untrusted documents and verify the sender

## Scenario
A supplier sends an invoice document you were not expecting. When opened in a preview, it asks you to “Enable Content” to display the invoice.

## Narration transcript
Scenario: A supplier sends an invoice document you were not expecting. When opened in a preview, it asks you to “Enable Content” to display the invoice. Safest response: Option B: Verify the invoice with the supplier through known contact details and report the suspicious request; do not enable content. Unexpected documents and requests to enable active content require independent verification. Option A is unsafe because Disconnecting does not make untrusted active content safe; it may still alter or persist on the device. Option C is unsafe because Uploading a business document publicly may disclose confidential data; use organization-approved analysis channels. Option D is unsafe because Unexpected active content can execute code and should not be enabled simply to view a document. In practice: Close the document without enabling content. Verify with the supplier using a known contact method and use approved security analysis if needed. Key takeaway: Do not enable macros or active content in an unexpected document to reveal what it contains.
