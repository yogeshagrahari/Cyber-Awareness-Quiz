# Phase 15 release report — 0.10.0-rc.8

**Scope:** deterministic dependency resolution and release-gate consistency. Video production and provider integration remain explicitly deferred.

## Change delivered

The React CI previously generated `package-lock.json` independently inside each Node.js matrix runner. Although the pinned npm CLI and exact package versions reduced variability, each runner could still resolve and test a separately generated dependency graph. Phase 15 introduces a single `resolve-dependencies` job using Node.js 26.13.1 and npm 12.2.2. It publishes one lockfile artifact for the run. Both Node.js matrix jobs download that exact artifact and use `npm ci`; they no longer independently resolve dependencies within the same workflow run. However, the lockfile is regenerated on each run and is not committed, so this provides run-level consistency—not deterministic dependency resolution across commits or repeat builds. Phase 16 replaces this temporary mechanism with a mandatory, reviewed, committed lockfile.

The source manifest generator now excludes generated release archives, dependency directories, test reports and environment files. This prevents the inventory from depending on archives that are regenerated after the manifest and avoids listing transient or sensitive local artifacts.

The React workflow continues to gate on dependency installation, high-severity npm audit, domain/content tests, official TypeScript project build, Vite production build, React distribution smoke, five Playwright desktop/mobile browser projects, and axe checks across the principal learner views. Failure diagnostics remain retained as workflow artifacts.

- React source and workflow static syntax: checked locally.
- Historical phase 14 application test evidence remains unchanged and is not represented as a phase 15 run.

## Outstanding gates — not claimed as passed

- The npm registry is unreachable in this environment. The lockfile must be generated by the new CI job, reviewed, and committed as `frontend/react-app/package-lock.json`.
- `npm ci`, `npm audit --audit-level=high`, the official TypeScript 7 project typecheck, Vite production build and React distribution smoke have not run here.
- Chromium, Firefox, WebKit, mobile emulation and axe browser acceptance have not run here. Existing local browser execution is blocked by the environment.
- Production TLS/HSTS, monitoring, off-host backups and restore/rollback require the actual deployment host.
- Independent cybersecurity/instructional-design review and learner evaluation remain outstanding.

## Release status

**Not production-approved.** The legacy packaged application remains the locally verified fallback. The React migration remains a release candidate pending successful network-enabled CI and operational review.
