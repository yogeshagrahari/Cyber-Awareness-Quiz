Scenario: A browser extension promises to summarize every page. It requests permission to read and change all data on every website, including internal work portals. Safest response: Option C: Check organizational approval, publisher provenance, necessity and permission scope before installation. Broad access to every site creates significant data and account exposure and should be justified and approved. Option A is unsafe because Using another person’s profile does not resolve the extension’s access or policy risks. Option B is unsafe because Private mode does not necessarily prevent an extension from accessing permitted page content. Option D is unsafe because Ratings do not establish the publisher’s trustworthiness or justify broad permissions. In practice: Do not install until the extension is approved and its permissions are proportionate to a documented need. Key takeaway: An extension with broad permissions can access sensitive page data; assess source and scope before use.
