# Explanations

`explanations.json` contains a question-level explanation record for all 115 core questions. It includes the correct-answer explanation and a rationale for each of the four options, plus the takeaway, defensive action, citations and video ID.

The full combined bank contains 133 question/explanation mappings. The 82 newly added question-level video mappings are explicitly deferred by owner direction; their written explanations remain available.
