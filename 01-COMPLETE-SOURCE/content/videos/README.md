# Question-level educational video assets

For each of the 45 planned questions this package now contains: a narration script/transcript (`scripts/`), scene-by-scene storyboard (`storyboards/`), generation prompt (`prompts/`) and WebVTT captions (`captions/`).

**No MP4s have been generated.** Manifest entries are `scripted_storyboard_caption_draft_media_not_generated`; this is not a completed video deliverable. Rendered assets must be created, quality-checked, caption-synchronized and human-reviewed before the status is changed.
