# Expert Challenge question bank

This optional module is maintained separately from the canonical 45-question core bank. It currently contains six organizational-level defensive decision scenarios. The module has its own JSON schema, explanation records, video manifest and traceability table. All content is a full draft pending external cybersecurity SME and instructional-design review.

The app unlock rule is at least 10 Advanced first attempts at 75% first-attempt accuracy. This is a provisional practice heuristic, not a validated competence threshold.

Run `python3 tests/content/validate_content.py` from the repository root to validate core and Expert Challenge mappings.
