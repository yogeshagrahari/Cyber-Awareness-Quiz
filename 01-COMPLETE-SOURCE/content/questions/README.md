# Question bank

The expanded draft is in `question-bank.json` and `question-bank.md`: 115 core questions (41 Beginner, 38 Intermediate and 36 Advanced) plus 18 Expert Challenge scenarios are tracked separately. The combined 133-question library covers 44 topic categories, with at least three questions per topic (Authentication has four). Every question has four answer options, one correct answer, option-specific rationales, a learning objective, scenario, defensive action, key takeaway, references and stable IDs.

**Status:** authored draft; pending cybersecurity SME, instructional-design, localization and accessibility review. Expert Challenge is intentionally not included in this initial 45.

Topic-level practice is available regardless of pathway lock state. An attempt on a locked pathway is saved as optional practice and does not count toward that level’s mastery threshold. All newly added items are pending independent cybersecurity and instructional-design review.
