Scenario: A project teammate asks you to upload a spreadsheet containing student IDs and contact details to a folder with “Anyone with the link can view” access. Safest response: Option A: Share only with the verified people who need it, using an approved restricted channel and minimum necessary data. Verify recipients and classification, then apply least privilege to access and content. Option B is unsafe because Temporary broad exposure is still exposure; access should be appropriately restricted before sharing. Option C is unsafe because Renaming does not remove sensitive content or limit access. Option D is unsafe because A personal mailbox may bypass organizational controls and create a new disclosure path. In practice: Confirm the business need and recipient list, use the approved storage service, disable public access, and set access expiry or review where supported. Key takeaway: Share the minimum necessary data with verified recipients using access controls appropriate to its sensitivity.
