Scenario: A team shares a folder containing internal project documents through an anonymous link that never expires. The folder is no longer being actively used. Safest response: Option A: Restrict access to named authorized accounts, set an expiry/review date and remove obsolete access. Restrict identities and duration, and review existing permissions according to data sensitivity. Option B is unsafe because A folder name does not change who can access its content. Option C is unsafe because Wider distribution increases exposure and does not establish authorization. Option D is unsafe because Convenience does not justify indefinite anonymous access. In practice: Remove anonymous access, grant only necessary users or groups, set expiry where available and periodically review permissions. Key takeaway: Cloud sharing should be identity-bound, least-privilege and time-limited when appropriate.
