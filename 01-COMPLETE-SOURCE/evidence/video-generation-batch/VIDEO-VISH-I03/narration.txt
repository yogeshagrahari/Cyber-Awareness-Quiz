Scenario: A caller claiming to be IT support says your laptop is infected and asks you to install a remote-access tool and read out an authentication code. Safest response: Option C: End the call and contact IT using the organization’s published helpdesk route. Independently verify support requests; never disclose authentication outputs to an unsolicited caller. Option A is unsafe because The code may authorize account access even without remote-control software. Option B is unsafe because Unverified remote access can give the caller control of the device. Option D is unsafe because A photo can be fabricated or copied and is not reliable identity verification. In practice: End the call. Contact the helpdesk using a known directory or portal and report the attempted remote-access and code request. Key takeaway: Caller ID, technical language and urgency are not proof that a caller is authorized.
