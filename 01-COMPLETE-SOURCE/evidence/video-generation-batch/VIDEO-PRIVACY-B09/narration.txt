Scenario: A person claiming to organize a campus event sends a form requesting your ID number, date of birth, home address and bank details to “confirm attendance.” Safest response: Option A: Verify the organizer through the official event channel and ask which fields are necessary before sharing anything. Confirm purpose and legitimacy, then disclose only the minimum required information using an approved channel. Option B is unsafe because A plausible event does not establish the form’s authenticity or justify collecting unrelated sensitive data. Option C is unsafe because False information can create operational problems and still expose you to malicious links or follow-up requests. Option D is unsafe because A different channel does not fix an unverified request or excessive data collection. In practice: Contact the event organizer using a published official channel. Do not submit unnecessary financial or identity data. Key takeaway: Check purpose, legitimacy and necessity before disclosing personal information.
