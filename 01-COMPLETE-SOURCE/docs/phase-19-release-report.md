# Phase 19 release report — 0.10.0-rc.12

**Scope:** release-job workspace parity, extracted-archive runtime acceptance, generated-cache exclusion, and exact source-inventory/archive equality. Video generation, provider integration, MP4 creation and media review remain deferred by the project owner.

## Issues corrected

1. **Clean release runner omitted the ignored legacy distribution.** `frontend/dist/` is ignored by Git and generated by `frontend/scripts/build.mjs`. The release job checked out fresh source, downloaded the React artifact and SBOM, then immediately ran a packager that requires `frontend/dist/`. The matrix test job's build output does not transfer into a separate job unless an artifact is uploaded/downloaded. The release job now runs the legacy static build itself and smoke-tests that distribution before generating its manifest.
2. **Packaged demo was not exercised in release CI.** The application-demo and React application ZIPs are now extracted in the packaging job and their smoke scripts are pointed at the extracted distributions through `CYBERAWARE_DIST_DIR` and `CYBERAWARE_REACT_DIST_DIR`. The workflow is configured to test the exact release artifacts before upload; this remote job has not yet run in the owner’s GitHub repository. The legacy demo check covers health, root HTML, canonical question data, GET/HEAD, 404, method rejection, security headers and graceful shutdown; the React check covers the Vite manifest/entry chunk, legacy compatibility page and canonical static data.
3. **Python bytecode and tool caches polluted the source inventory.** Python test execution had created `__pycache__/*.pyc` files which were included in the source manifest and archive. The manifest generator, JavaScript verifier, ZIP exclusions and archive safety checks now share exclusions for `__pycache__`, pytest/mypy/ruff caches, generic `.cache`, coverage and virtual environments. `.gitignore` now excludes Python caches and compiled bytecode too.
4. **Archive bytes were not re-hashed after extraction.** After checking exact path equality, the packager now extracts the full-source ZIP to a temporary directory and reruns the SHA-256/size verifier against the extracted bytes. Temporary extracted content is removed even on failure.
5. **Archive validation checked only for missing files.** The packager previously ensured every manifest file appeared in the ZIP but did not reject additional unmanifested files. It now requires exact equality between the archive's regular-file entries and the manifest inventory plus `package-manifest.json`, rejects duplicate entries, excluded paths and path traversal.
6. **Release metadata consistency.** Packaging now fails if the legacy and React package versions differ, and a React production build must contain a non-empty assets directory before it can be archived.
7. **CI documentation.** Updated the stable branch-protection gate matrix count and documented the self-contained release build, archive extraction smoke, inventory exclusions and fail-closed behavior.
